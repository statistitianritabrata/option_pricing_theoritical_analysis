# Statistical Analysis of Option Pricing

## Overview

This project presents a comparative study of option pricing models.

The study focuses on:

- Black-Scholes Model
- Monte Carlo Simulation
- Heston Stochastic Volatility Model
- Model Calibration
- Volatility Smile Analysis
- RMSE and MAPE Evaluation

## Objectives

- Estimate option pricing model parameters
- Compare theoretical and market prices
- Study stochastic volatility effects
- Evaluate model performance statistically

## Tools Used

- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
